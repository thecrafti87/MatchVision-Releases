# MatchVision

MatchVision liest Anzeigetafeln in Echtzeit: Spielstand, Uhr, Namen und alles, was sonst auf der Tafel steht. Die Werte gibt es an andere Programme weiter, zum Beispiel an eine Grafik im Livestream.

Aktuelle Version: **0.3.0**

## Herunterladen und starten

1. [MatchVision.zip herunterladen](https://github.com/thecrafti87/MatchVision-Releases/releases/latest/download/MatchVision.zip)
2. Die Datei in einen Ordner entpacken, in den du schreiben darfst, zum Beispiel nach „Dokumente". Nicht nach „Programme".
3. Im Ordner `MatchVision.exe` doppelklicken.

Beim ersten Start kann Windows fragen, ob das Programm ausgeführt werden soll, weil es nicht signiert ist. Über „Weitere Informationen" und „Trotzdem ausführen" geht es weiter.

Gebraucht wird Windows 10 oder 11 (64 Bit). Für NDI-Quellen muss zusätzlich NDI Tools installiert sein.

## Neue Versionen

MatchVision sieht beim Start selbst nach, ob es eine neue Version gibt, und zeigt dann oben im Fenster einen Hinweis. Installiert wird erst nach einem Klick auf „Jetzt aktualisieren". Felder und Einstellungen bleiben erhalten.

Wer lieber von Hand aktualisiert: die neue `MatchVision.zip` herunterladen und über den alten Ordner entpacken. Die Dateien `config.json` und `api_token.secret` sind nicht im Paket und bleiben, wie sie sind.

## Was steckt drin

In diesem Repository liegen nur die fertigen Programme, nicht der Quellcode. Die Lizenzen der mitgelieferten Bibliotheken stehen im Programmordner unter `Lizenzen`.
